計算式と前提
Spo = 1360 W/m²（太陽定数・固定） 標準子午線 = 135°E（固定）／地方子午線 = 経度 − 135 LC = (経度 − 135) / 15 … 経度補正 [hr] f = 279.575 + 0.9856 J [deg] ET = (−104.7 sinf + 596.2 sin2f + 4.3 sin3f − 12.7 sin4f − 429.3 cosf − 2 cos2f + 19.3 cos3f) / 3600 … 均時差 [hr] (式11.4) t0 = 12 − LC − ET … 南中時刻 [hr] (式11.3) sinδ= 0.39785 sin(278.97 + 0.9856J + 1.9165 sin(356.6 + 0.9856J)) … 赤緯 (式11.2) cosψ= sinΦ sinδ + cosΦ cosδ cos(15(t − t0)) … (式11.1) m = Pa / (101.3 cosψ) … 大気路程 (式11.12) Sp = Spo τ^m … 法線面直達 (式11.11) Sb = Sp cosψ … 水平面直達 (式11.8) Sd = 0.3 (1 − τ^m) Spo cosψ … 水平面散乱 (式11.13) St = Sb + Sd … 全天日射 (式11.13) 積算日射量 = Σ St × 60 秒 × 10⁻⁶ (1分刻み・St>0 のみ) 大気圧（標高 h [m] より・国際標準大気） Pa = 101.3 × (1 − 2.25577×10⁻⁵ h)^5.25588 [kPa] 大気透過率 τ 曇天 : 0.45（固定） 快晴 : τ = 0.70 + 0.10 cos(2πJ / 365) → 12月中旬 0.80 ／ 7月中旬 0.60 ／ 春秋 0.68〜0.72
