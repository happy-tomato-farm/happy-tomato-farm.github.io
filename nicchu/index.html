日中平均の計算

ハッピートマトファーム

外の天気から見込む（ハウス内の日中平均）

アグリネットの値から計算する

ハウス内の気温を、分かる時刻だけ入れてください。空いた時刻は前後の値を直線でつないで計算します。

計算の考え方と、どれくらい当たるか

「実況＋予報で」の式

冬のハウス内の昼の気温は、暖房と換気の設定でほぼ決まり、そこに「晴れた分だけ上がる」「外が暖かい分だけ少し上がる」が足されます。これを月ごとの式にしました。

ハウス内の日中平均 ＝ a ＋ b × 外気の日中平均 ＋ c × 日照の割合
  • a … 曇りで外気0℃のときのハウス内（暖房・換気の設定で決まる分）
  • b … 外が1℃暖かいと、ハウス内が何℃上がるか
  • c … 一日じゅう晴れると、曇りの日より何℃上がるか
  • 外気の日中平均 … 鹿沼アメダスの、日の出〜日の入りの気温の平均
  • 日照の割合 … 鹿沼アメダスの日照時間 ÷ 昼の長さ（終日晴れで1、終日曇りで0）

いまの時刻より先は予報で埋める

  • 日の出〜いままでは、気象庁アメダス（鹿沼）の10分ごとの実況を使います
  • いま〜日の入りは、気象庁の地域時系列予報（栃木県南部・宇都宮。夜温設定の⑤と同じ）を使います。気温は宇都宮の予報に「鹿沼 − 宇都宮 の昼の差」を足します
  • 予報の天気は、日照の割合に直して使います（過去の観測から求めた値）
  • 日の入りを過ぎて開けば、全部が実況で計算されます

前提と、当たりにくいとき

  • 式は 2024〜2026年度の10〜4月、中央・東をあわせた日の記録から作りました（それより前は管理のしかたが違うため使っていません）
  • 5〜9月は外の記録を取っていないので、式がありません
  • 10月・4月はずれが大きめです。外が暖かい時期は、換気の開け方しだいでハウス内が大きく変わり、外の値だけでは読み切れません
  • 換気・暖房の設定やカーテンの使い方を大きく変えた日は、過去の日と前提が違うので外れやすくなります
  • 予報が外れれば、その分ずれます（上の表の「ずれ」は、日の入り後に実況だけで計算したときの値です）
  • アグリネットの値が見られるときは「数値を入れる」のほうが確かです

「数値を入れる」の計算

入れた時刻の値を直線でつなぎ、日の出〜日の入りの時間で平均します。最初の値より前（日の出まで）と、最後の値より後（日の入りまで）は、その値のまま延ばします。

出典

気象データ：気象庁ホームページ（アメダス・地域時系列予報・過去の気象データ）を加工して作成。ハウス内の気温：4週記録表（ハウス内センサー）。
